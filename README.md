# Tasting Notes

Log wine and whisky tasting notes in Obsidian: producer, vintage, nose, palate, finish, ratings, and cellar tracking.

## Features

- **New Tasting Note** – log wines, whiskies, beers, and more with detailed tasting fields
- **Wine fields** – colour, grape varieties
- **Whisky fields** – distillery, age statement, ABV, cask type
- **Add to Cellar** – mark any note as "in cellar" with quantity and purchase date
- **Tasting Sidebar** – All / Wine / Whisky tabs, sorted by rating
- **Settings** – configure tasting notes folder

## Usage

Open the command palette and search for "Tasting Notes" to access all commands.
